# Water Garden

## ▶ [今すぐテストプレイ](https://tk-0238.github.io/...../play.html)

**PC・iPhone・iPad対応。** GitHub上では上のリンクを1回押すだけで、最新のGitHub Pages版をそのままブラウザでプレイできます。

> iPhone / iPad: Safariで開き、最初に水面を1回タップして「動作と方向」へのアクセスを許可してください。その後は端末を揺らすと水面全体にさざなみと流れが起きます。指ドラッグも併用できます。  
> PC: マウスで水面をドラッグしてください。

マウス／指で水面をかき混ぜると、流れと波が生まれ、浮いている葉が水流に沿って運ばれるインタラクティブな浅瀬表現です。

## 主な表現

- CPU波動シミュレーションによる水面の伝播
- ドラッグ軌跡から生成する2D流速場
- WebGL 2シェーダーによる小石の屈折・微細な色分散
- 波頭だけに出る控えめなコースティクス／ハイライト
- 流速場をサンプリングして移流する葉っぱ
- PCのマウス操作とスマホ／タブレットのPointer Eventsに対応
- iPhone / iPadの加速度・ジャイロ入力に対応し、端末を揺らす強さ・方向に応じて広域のさざなみと流れを生成
- 外部画像・外部ライブラリなし

## 実行

静的サイトなので、HTTPサーバーから `index.html` を配信するだけで動作します。

```bash
python3 -m http.server 8080
```

その後、ブラウザで `http://localhost:8080` を開いてください。

## 推奨環境

WebGL 2対応の新しいChrome / Edge / Safari。GPU負荷と高DPI端末を考慮し、描画DPRは最大2に制限しています。
